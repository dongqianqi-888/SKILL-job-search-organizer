# 用户画像采集模板

适配等级评估依赖用户画像。**用户上传简历附件（图片/PDF）时优先自动解析简历获取画像，不逐项询问**；仅当简历未提供、或画像中影响适配等级判断的字段缺失时，才向用户补齐。

## 简历附件解析（自动）

- 用户上传简历截图、照片、PDF 时，先完整读取并解析简历内容，自动提取画像字段：
  专业/学历、毕业时间、核心技能（SQL/Python/R 等）、实习与工作经历、求职意向岗位、期望城市、语言能力、作品集/主页（GitHub、ORCID 等）。
- 解析结果直接作为用户画像使用，无需用户逐项填写。
- 简历信息以用户提供的现状为准；用户后续口头修正（如"期望城市改了"）以最新为准。
- 简历未提供、或影响适配等级判断的字段缺失时，才一次性提问补齐（≤3个问题）。
- 长图简历被系统过滤时，先裁切分段读取，确保完整解析。

## 必填字段

| 字段 | 用途 | 示例 |
|---|---|---|
| 目标职能类别 | 第5列"目标职能岗"的判定口径 | 数据/采购/项目/产品/分析 |
| 求职意向岗位类型 | 适配等级的岗位匹配基准 | 数据分析师、数据产品经理、行业研究 |
| 期望工作地点 | 第7列"地点可投性"的命中基准 | 上海/杭州/江浙 |
| 毕业时间 | 判断"届别"与校招时效（2027届=2026年秋招~2027年春招） | 2027年6月 |

## 建议收集字段

| 字段 | 用途 | 示例 |
|---|---|---|
| 专业 | 判断岗位专业匹配度 | 数据科学与分析硕士 |
| 核心技能 | 匹配岗位技能要求（SQL/Python/R/统计/建模等） | SQL、Python、R、Excel看板、统计建模 |
| 实习/工作经历 | 匹配行业与岗位类型（行研/产品/数据分析等） | SMM大宗商品行研、产品运营、HR大数据 |
| 语言能力 | 判断外企/海外岗可投性 | 雅思6.0、可处理英文财报 |
| 可接受海外/异地 | 扩大或收窄地点命中范围 | 人在马来西亚可面海外岗，外派可接受 |
| 求职时间线 | 排序与截止判断 | 2027届秋招网申进行中 |

## 提问方式

- 用户已给出（如简历截图、过往对话）则不重复问。
- 缺失字段按优先级一次问 ≤3 个问题，用选择题或自由输入均可。
- 低影响字段（如语言能力）可默认假设后注明，不阻塞流程。
- 用户画像是静态的，同一次会话内多批核查复用同一画像；画像变化（如期望城市调整）时以最新为准并在交付中注明。

## 画像示例（真实案例）

- 专业：马来西亚 UKM 数据科学与分析硕士（预计2027年6月毕业）
- 技能：SQL / Python / R / Excel 看板 / 统计建模 / 时间序列
- 经历：大宗商品行业研究实习（数据链路/量化模型/数据治理）、AI产品运营、HR大数据
- 求职意向：数据分析 / 数据产品经理；期望上海/杭州/江浙；人在马来西亚可接受海外岗
- 对海外公司：英语环境 + 马来西亚本地岗优先标记
- 对研发型公司（芯片/半导体/硬件）：标注"偏研发，与数据分析背景匹配度一般"

## 采集时机

- 首批核查前完成画像确认；后续批次默认复用，除非用户主动提供新画像信息。
