# Job Search Organizer · 岗位搜索整理 Skill

一个开箱即用的 AI Agent 技能（Skill）：**把一批公司名单，变成一份"官网已核实的校招岗位清单 + 按你的简历评估的适配等级表"**，并自动整理成表格交付给你。

> 它解决的真实场景：你刷到一屏"XX公司 2027 届校招启动"的推送，想知道——这些公司官网**真的**在招吗？招的岗位里有没有**适合你**的（数据分析/产品/采购/项目……）？工作地点在不在你想去的城市？这家公司值不值得投？
>
> 这个 Skill 会逐家去官网核实，然后按你的简历把公司分成"高适配 / 中高适配 / 中适配 / 低适配"，整理成一张表，告诉你先投谁。

## 它能做什么

| 输入 | 输出 |
|---|---|
| 一屏公司校招截图 / Logo 矩阵图 | 每家公司官网的校招状态（有校招/已截止/无/未确认） |
| 一段公司名单文字 | 是否有你的目标职能岗（数据/采购/项目/产品/分析类） |
| 一份公司表格（已有 collect 表） | 每家公司的适配等级（高/中高/中/低） |
| 你的简历/求职意向 | 按批次+适配等级排序的飞书表格 + 投递优先级建议 |

**适用人群**：应届毕业生、实习转正求职者、想批量筛公司岗位的任何人。

## 工作原理（30秒看懂）

```
你的输入（公司名单 + 简历/求职意向）
        │
        ▼
┌─────────────────────────────────────┐
│  第1步 解析输入                       │
│  识别公司名单 + 你的画像              │
│  （专业/技能/期望城市/毕业时间）      │
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│  第2步 规模化判断                     │
│  公司 ≥8 家 → 自动分片并行核查        │
│  公司 <8 家 → 逐个核查                │
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│  第3步 逐家官网核查（核心）           │
│  定位官网 → 找招聘入口 → 确认校招状态 │
│  → 判断目标职能岗 → 提取证据 → 记录地点│
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│  第4步 适配等级评估                   │
│  按你的简历：高适配/中高适配/中适配/低 │
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│  第5步 整理表格                       │
│  9列结构 → 按批次+适配等级排序        │
│  → 写入飞书表格                       │
└─────────────────────────────────────┘
        │
        ▼
   交付：飞书表格链接 + 投递建议
```

**核心原则（为什么结果可信）**：
- **只认官网证据**：截图、公众号推送、第三方招聘站都只是"线索"，最终状态以公司官网/官方招聘页为准。
- **查不到就说"未确认"**：绝不猜测、不编造，找不到官网就标未确认。
- **每个结论可追溯**：每家公司的"有校招/有岗位"都附官网 URL 作证据。

## 安装步骤（3步，不用写代码）

### 前提条件

- 一个支持 Skill 机制的 AI Agent 环境（如豆包办公/工作模式）。
- 能找到你的技能目录（见下方第 2 步）。

### 第 1 步：下载本仓库

打开本仓库页面，点击绿色按钮 **Code → Download ZIP**，解压到本地任意位置。

### 第 2 步：找到你的 Skills 目录

在你的 Agent 工作环境中，Skills 通常安装在如下目录之一（取决于你的环境）：

```text
<环境目录>/workspace/.user_skills/     ← 用户技能目录（推荐放这里）
<环境目录>/workspace/.skills/          ← 系统技能目录
```

如果不确定，打开环境配置文件或询问你的 Agent："我的 skills 目录在哪？"

### 第 3 步：把文件夹放进去

把解压出来的 **`job-search-organizer` 整个文件夹**（注意是里面那一层，包含 `SKILL.md` 的那层）复制到 `.user_skills/` 目录下，最终结构如下：

```text
.user_skills/
└── job-search-organizer/
    ├── SKILL.md                        ← 技能入口（必须有）
    ├── references/
    │   ├── field-rules.md              ← 字段判定口径
    │   └── user-profile.md             ← 用户画像模板
    └── scripts/
        └── prepare_table_payload.py    ← 表格排序工具
```

完成后重启/刷新你的 Agent 环境，让技能被加载。

> 装好后可以验证：随便问一句"帮我看这些公司有没有校招岗位"，如果 Agent 开始按 Skill 流程跑，就说明安装成功。

## 怎么使用（对话示例）

装好后，直接对 Agent 说人话即可，例如：

| 你说 | Agent 会做 |
|---|---|
| "帮我看这 27 家公司有没有校招岗位"（附 Logo 截图） | 识别公司 → 逐家官网核查 → 整理表格 |
| "帮我查这些企业官网的招聘记录并整理成表"（附名单文字） | 同上，产出 9 列表格 |
| "帮我筛出有数据分析岗位的公司" | 按你的目标职能岗筛选 + 适配等级排序 |
| "帮我把这 21 家追加进 collect 表（批次3）" | 复用已有表格，追加新批次 |
| "帮我把表格按批次排序" | 批次升序 + 批次内适配等级降序重排 |

**首次使用**，Agent 可能会先问你几个问题（用于评估适配等级）：

```
你的专业/毕业时间？
求职意向岗位是？（数据分析 / 数据产品经理 / 行业研究…）
期望工作地点？（上海/杭州/江浙 / 海外 / 都可以）
你的核心技能？（SQL / Python / R…）
```

如实回答即可，越详细，适配等级判得越准。

## 整理出来的表格长什么样

飞书表格，9 列，按"批次 → 批次内适配等级（高→低）"排序：

| 列名 | 说明 | 示例 |
|---|---|---|
| 批次 | 第几批核查（追加已有表则续号） | `3` |
| 公司 | 官方完整名称（可附英文名） | `高知特 Cognizant` |
| 官网/招聘入口 | 官方招聘页 URL | `https://www.cognizant.com/cn/zh` |
| 校招状态 | 有校招 / 已截止 / 无校招 / 部分匹配 / 未确认 | `有校招` |
| 目标职能岗 | 是否有你的目标岗位类别：有/无/部分/未确认 | `有` |
| 证据说明 | 岗位名 + 栏目名 + 来源页面 | `BI数据分析工程师（上海），SQL/数仓对口` |
| 地点/可投性 | 工作地点 + 是否命中你的期望区域 | `上海/杭州` |
| 备注 | 截止提醒、主体存疑、投递提示等 | `2027届网申进行中` |
| 适配等级 | 高适配/中高适配/中适配/低适配 | `高适配` |

**表格开头就是最值得投的公司**，从上往下投即可。

## 适配等级怎么判的

综合三要素：**有没有你的目标职能岗 × 地点命中不命中 × 简历匹配度高不高**

| 等级 | 判定标准 | 例子 |
|---|---|---|
| 🟢 高适配 | 有明确目标职能岗 **且** 地点命中你的期望城市 | 吉利数据治理岗（杭州）+ 你是数据分析方向 |
| 🔵 中高适配 | 有目标职能岗但地点不完全命中；或近似岗位+地点命中 | 安克有产品/数据岗但base深圳 |
| 🟡 中适配 | 有职能岗但数据/分析类不明确，或地点不匹配 | 太极股份项目/产品岗但无江浙沪 |
| ⚪ 低适配 | 纯研发/工程/生产/销售岗；或已截止/主体存疑 | 芯片公司全部IC设计岗 |

## 常见问题 FAQ

**Q1：为什么查不到的公司要标"未确认"，不能猜吗？**
不能。猜测会污染你的投递决策（比如你以为某家有数据分析岗投了，结果没有）。宁可标"未确认"提醒你核实，也不编造。

**Q2：截图里明明写了"校招启动"，为什么 Agent 还说要去官网核实？**
截图/公众号推送可能滞后或夸大。官网招聘页才是"现在还能不能投"的权威依据。

**Q3：公司太多会不会很慢？**
≥8 家会自动分片并行核查，几十家也能在合理时间内跑完。

**Q4：我已经有一张 collect 表了，能直接追加吗？**
可以。告诉 Agent "追加进 collect 表"，它会用新批次号续排，口径与旧批次完全一致。

**Q5：想改目标职能岗口径（比如只要数据分析岗）？**
直接告诉 Agent 你的岗位偏好，第 5 列判定会随之调整。

**Q6：这个 Skill 会泄露我的隐私吗？**
不会。它只在你主动提供的信息（公司名单、你的求职意向）基础上工作，所有核查都基于公开的官网信息。
